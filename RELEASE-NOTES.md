NurimAI 0.3.0

- Windows and Mac desktop chat with a movable mascot.
- Shared NurimAI server: users do not enter API keys.
- Gemini/Groq failover, bounded shared free usage, and optional personal credentials.
- Windows Setup supports automatic update downloads and installation on full app exit.
- The old Windows portable ZIP cannot receive updates. Install this Setup once.
- Mac universal package supports Apple Silicon and Intel. Unsigned Mac builds require manual updates; automatic Mac updates activate only for a signed, notarized build.
- Chat stays in memory; export important text before quitting or installing an update.

AI availability is limited by shared free quotas. API keys are never included in release files.
